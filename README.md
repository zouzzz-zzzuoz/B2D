B2D est une application pour Android (.apk).\
Il s'agit d'un lecteur xlsx pour bon de débit de STECO Industries.\
Il doit être couplé avec les applications gratuites Apk4Tag et Gestionnaire de fichiers + (Giles by Google).\
\
\
3 règles à respecter :\
1- Le nom du fichier de traçage doit avoir exactement le même que le nom dans le bon (Bon.xlsx) mais sans le format de fichier (.tag, .pdf...). L'application recherchera les .tag puis les autres formats (.dxf, .pdf, .png...). Le suffixe n'est pas nécessaire (-CISAILLE...).\
  2- La cellule COUPER doit (toujours) être en G7, c’est la référence.\
  3- Il faut absolument mettre les fichiers de traçage dans le dossier fichiers.\
  \
Pour appel : les formats de fichier .dwg ou .xlsx ou .xls ne sont pas pris en compte par Apk4Tag.
